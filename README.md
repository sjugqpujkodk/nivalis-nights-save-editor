## Overview

Nivalis Nights Save Editor is a desktop tool for modifying Nivalis Nights save files, enabling players to adjust in-game currency, relationship levels with NPCs, owned property and upgrades, and city reputation values. It targets the cyberpunk life-sim's save format to provide broad access to game state without console commands.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Nivalis Nights Save Editor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Currency Edit** | Adjust player cash and digital currency balances in the save file |
| **Relationship Values** | Set relationship levels with any named NPC character |
| **Property Owned** | Toggle ownership of apartments, businesses, and city properties |
| **City Reputation** | Edit faction and district reputation values for all factions |
